# Freelance-marketplace-


A simple freelance marketplace demo built with HTML, CSS, and JavaScript.

## Features
- Freelancer listings with name, skill, and hourly rate
- Search filter by skill
- Job posting form with title, company, and description
- Confirmation alert when posting a job
